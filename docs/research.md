## 2. Asset licensing — what is actually usable

### 2.1 Wikimedia Commons — PRIMARY image source (verified pipeline works)

Network reality of this machine (tested 2026-10-01):
- `https://commons.wikimedia.org/w/api.php` → **connection reset (blocked)**. Direct Commons Action API unusable.
- `https://commons.wikimedia.org/wiki/...` → blocked. `commons.m.wikimedia.org` → 301 redirect to blocked host.
- `https://api.wikimedia.org/**` → **works (200)** — Wikimedia REST API.
- `https://upload.wikimedia.org/**`, `https://thumb.wikimedia.org/**` → **works** — file downloads/thumbnails.

Working pipeline (ASSET-IMAGES must implement exactly this):
1. Search: `GET https://api.wikimedia.org/core/v1/commons/search/page?q=<query>&limit=<n>`
   → `{pages:[{key:"File:...", title, excerpt}]}`.
2. File meta: `GET https://api.wikimedia.org/core/v1/commons/file/<File:Name>`
   → `original.url`, `preferred.url` (thumb), `latest.user.name` (uploader), width/height/size.
3. License + author: `GET https://api.wikimedia.org/core/v1/commons/page/<File:Name>/html`
   → raw file-page HTML; parse the Licensing section (contains e.g. "licensed under the Creative
   Commons Attribution-Share Alike 4.0 International license", author/`{{Artist}}` output).
   Verified: license text + author extract cleanly (test file:
   `File:Porsche_911_GT3_Touring,_IAA_2017,_Frankfurt_(1Y7A2766).jpg` — CC BY-SA 4.0, author
   "MB-one"/Matti Blume).
4. Download originals from `upload.wikimedia.org` URLs (strip `?utm_*` query), convert locally.
5. Every asset record: `{fileTitle, sourceUrl, downloadUrl, license, author, attributionHtml, retrievedAt}`
   → `/data/credits.json`; rendered at `/credits`.

Rule: **only** images whose parsed license is CC0 / CC BY / CC BY-SA (or public domain) are used.
No hotlinking. No ambiguous licenses.

### 2.2 Porsche Newsroom — NOT rehostable (checked terms, 2026-07-24 version)
Terms state content is "intended exclusively for use by journalists as a source for their own
media reporting", "not intended for commercial use", and "not permitted to pass on texts, images,
audio or video data to unauthorised third parties"; book/commercial image use needs approval from
`archiv@porsche.de`.
→ **Decision: do not download or rehost Newsroom images.** Use Newsroom only as a *factual
source* (cited in JSON `sources[]`). Optional: link out to Newsroom articles. Mark in STATUS.md
that press-kit photography is unused for license reasons.

### 2.3 Sketchfab 3D — embeds (user decision this session)
- Search API works: `GET https://api.sketchfab.com/v3/search?type=models&q=porsche+911&downloadable=true`
  → results include `license.label` ("CC Attribution", "CC Attribution-ShareAlike"), `uid`, `viewerUrl`.
- Download API returns **401 without OAuth** → cannot pull GLBs programmatically.
- User decision: **use official Sketchfab iframe embeds** for hero cars; local GLBs only if found
  on a direct-download CC source (e.g. GitHub repo with explicit license). Attribution recorded
  in `/data/credits.json`. Embed = `https://sketchfab.com/3d-models/<slug>/<uid>?embed=1`.
- Verified findable CC candidates (from search API): "(FREE) Porsche 911 Carrera 4S" (CC BY-SA,
  uid d01b254483794de3819786d93e0e1ebf), "FREE 1975 Porsche 911 (930) Turbo" (CC BY,
  uid 8568d9d14a994b9cae59499f0dbed21e), "2024 Porsche 992 GT3 R" (CC BY, uid b76c9b2ae2d548c3869426eac4ab8a19),
  Ddiaz Design collection (74 Porsche models — verify per-model license labels before embedding).

### 2.4 YouTube — embed only, never rehost
Lazy `<iframe>` (or lite-youtube placeholder → facade) with `youtube-nocookie.com/embed/<id>?rel=0`.
Verify each ID live with `https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=<id>&format=json`
(no API key needed). Poster frame: `https://i.ytimg.com/vi/<id>/maxresdefault.jpg` (hotlink to
YouTube's own CDN is standard for embeds; if we must avoid, use `hqdefault.jpg` fallback or a
Commons image poster). Curated per generation by ASSET-VIDEO.

### 2.5 Everything else
- Fonts: self-hosted Google Fonts (OFL) — one display face + one mono (chosen in tokens).
- Icons: inline SVG / lucide (MIT).
- No other stock image sites (Unsplash/Pexels "free" ≠ safe for a curated build without
  per-file records; Commons only).

## 5. Explicit "missing" policy

If an image, model, video or spec cannot be found under a verifiable license, the owning agent
writes `missing` (or `null` + reason) into its data file. The lead lists all `missing` entries in
`/docs/STATUS.md`. Nothing is ever fabricated.
